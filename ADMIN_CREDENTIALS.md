## 📝 How to Create Admin User

1. **Visit the auto-setup page:**
   ```
   http://localhost/2026sjs/auto-setup-admin.php
   ```

2. **The script will automatically:**
   - Create the users table if it doesn't exist
   - Create an admin user with the credentials above
   - Display the login information

3. **Login to Admin Panel:**
   - Go to: `http://localhost/2026sjs/login.php`
   - Enter the email and password above
   - You'll be redirected to the admin panel
