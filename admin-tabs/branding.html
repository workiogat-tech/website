How to edit the browser tab & school name
  1. School Name sets the browser tab title (example: ZION SCHOOLS - Home) and the name used across the site.
  2. Favicon is the small icon next to the tab title — pick an image from the media library, then Save.
  3. After saving, open the homepage and press Ctrl+F5 (or close the tab and reopen) so the browser drops the old icon.
  4. For the bottom line © ZION SCHOOLS. All rights reserved., open the Footer tab and edit Copyright Text.

Shows as “Your Name - Home” in the browser tab.
