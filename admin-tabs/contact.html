School map

Open Google Maps, find the school, click Share, then Embed a map, and copy the HTML. Paste it here. A normal Google Maps link also works. Save contact details, then open the Contact page to see the map.

Or enter the coordinates

In Google Maps, right-click the school. The first line looks like -1.292100, 36.821900. The first number is latitude. The second is longitude. Save, and the Contact page drops a pin there when no embed code is set.
