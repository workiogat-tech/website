Colors

Branding sets the default school color. This screen stores a palette for each part of the site. A page uses its own primary color when one is saved.

Primary is headings and links. Secondary is the darker shade. Background is the page background. Text is paragraph text. Accent is highlights. Hover is the color when a visitor hovers a button. Choose a color, then click Save all colors.
